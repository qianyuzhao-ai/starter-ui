Starter UI

实验项目的最小设计规范。颜色、字号、间距从第一天起统一成 token，并同时支持 Light 和 Dark。项目长大后换品牌色或调整字号，只改 token，不用全局搜索替换。

三条原则

只用语义 token

写 text-fg-muted，不写 text-zinc-600 或色值。主题切换靠 token，组件里几乎不需要 dark:。

少即是多

1 个品牌色、3 级文字色、9 个字号样式、8 档间距、4 档圆角。不够用时先复用，再新增。

两个主题同时设计

每加一个颜色，Light 和 Dark 的值同时定，并在两种背景上各验一次对比度。

颜色

每个色块左半是 Light 值，右半是 Dark 值。对比度按各自主题的 bg 计算，文字类 token 在 bg、surface、surface-raised 三层背景上都 ≥ 4.5:1。

Token色块LightDark对比度 L / D用途
  • 背景用 #121212 深灰，不用纯黑；主文字用 #ececee，不用纯白，避免光晕和疲劳。
  • 彩色在深色下提亮、降饱和，所以放在彩色上的文字（primary-fg、danger-fg）在深色下反而变深。
  • 深色下阴影几乎不可见，层级靠 surface-raised 变亮来表达。
  • 状态色只表达状态，始终配合图标或文字，不只靠颜色。

字体

用系统字体栈，不加载 Web 字体，启动快、中文渲染稳定。字号 / 行高单位为 px。

  • Web 端默认正文用 body（14px），移动端默认用 body-lg（16px）。
  • 字重只用 400 / 500 / 600 / 700。不用 300 以下的细体，深色下会发虚。
  • 中文正文行高约为字号的 1.5–1.6 倍，标题收紧到 1.25–1.3。
  • 一个页面最多 3 个字号层级，层次靠字重和 fg / fg-muted 拉开。
  • 移动端输入框字号不小于 16px，否则 iOS Safari 聚焦时会放大页面。

间距与圆角

  • 组件内部 4–16，组件之间 16–32，区块之间 32–64。
  • 页面边距：移动端 16，Web 端 24 起。
  • 嵌套圆角：外层 = 内层 + 内边距。

组件

下面的组件都是可以直接交互的实时预览，切换上方主题即可对比。每个组件附 Tailwind 写法，项目里建议各封装成一个组件，用 props 切换变体。

Button

primary 一屏只放一个；secondary 用于并列的次要操作；ghost 用于工具栏和行内；danger 用于不可逆操作，放在确认弹窗里。尺寸：sm 表格行内，md Web 默认，lg 移动端默认（44px 最小触控区域）。文案用动词开头，图标按钮必须加 aria-label。

Tailwind 写法
<button class="inline-flex items-center justify-center gap-2 h-9 px-4 rounded-md
  text-label font-medium transition-colors
  focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-primary
  disabled:opacity-50 disabled:cursor-not-allowed
  bg-primary text-primary-fg hover:bg-primary-hover">发送邀请</button>

<!-- 变体：替换最后一行 -->
primary    bg-primary text-primary-fg hover:bg-primary-hover
secondary  bg-surface text-fg border border-border-strong hover:bg-border
ghost      bg-transparent text-fg hover:bg-surface
danger     bg-danger text-danger-fg hover:bg-danger-hover

<!-- 尺寸：sm → h-8 px-3，lg → h-11 px-6 -->

Input

只能包含小写字母和连字符
请输入完整的邮箱地址
创建后不可修改

结构：标签 → 输入框 → 帮助文字或错误提示，间距 4px，表单项之间 24px。边框用 border-strong，保证输入框边界 ≥ 3:1。不要只用占位符代替标签。移动端改为 h-11 text-body-lg。错误提示写清楚怎么改。

Tailwind 写法
<label class="flex flex-col gap-1">
  <span class="text-label font-medium text-fg">项目名称</span>
  <input class="h-9 w-full px-3 rounded-md bg-bg text-body text-fg
    border border-border-strong placeholder:text-fg-subtle
    focus:outline-none focus:border-primary focus:ring-1 focus:ring-primary
    disabled:opacity-50 disabled:bg-surface
    aria-[invalid=true]:border-danger"
    placeholder="例如：landing-test">
  <span class="text-caption text-fg-subtle">只能包含小写字母和连字符</span>
</label>

<!-- 错误：input 加 aria-invalid="true"，提示文字换成 text-danger -->

Card

邀请新成员

成员可以查看和编辑这个项目，你随时可以移除他们。

删除项目？

项目里的所有数据会被永久删除，无法恢复。

默认用 surface + border，用于页面内分组；浮层用 surface-raised + shadow-lg，用于弹窗和 Popover。内边距 16，内容多时 24。卡片不嵌套卡片，需要再分组用分割线。主操作放最右。

Tailwind 写法
<div class="bg-surface border border-border rounded-lg p-4">
  <h3 class="text-h3 font-semibold text-fg">邀请新成员</h3>
  <p class="text-body text-fg-muted mt-1">成员可以查看和编辑这个项目。</p>
  <div class="flex justify-end gap-2 mt-4">
    <!-- secondary + primary 按钮 -->
  </div>
</div>

<!-- 浮层：bg-surface-raised border border-border rounded-lg p-4 shadow-lg -->

Badge

草稿 新功能 运行中 即将到期 构建失败

状态用"中性文字 + 彩色圆点"，而不是彩色字配同色浅底：后者在浅色模式下 12px 文字对比度只有约 4:1，达不到 AA；圆点方案文字始终清晰，色盲用户也能靠文字理解。文字 2–4 个字；Badge 不可点击，需要点击用 ghost 按钮。

Tailwind 写法
<!-- 状态：圆点换成 bg-success / bg-warning / bg-danger，中性状态去掉圆点 -->
<span class="inline-flex items-center gap-1 h-[22px] px-2 rounded-sm
  border border-border text-caption font-medium text-fg-muted">
  <span class="size-1.5 rounded-full bg-success"></span>运行中
</span>

<!-- 品牌：新功能、Beta -->
<span class="inline-flex items-center h-[22px] px-2 rounded-sm
  bg-primary-subtle text-primary text-caption font-medium">新功能</span>

主题切换脚本

放在 <head> 里，先于页面渲染执行，避免闪白。

<script>
  const t = localStorage.getItem('theme');
  const dark = t ? t === 'dark' : matchMedia('(prefers-color-scheme: dark)').matches;
  document.documentElement.classList.toggle('dark', dark);
</script>
  • 新增颜色或字号时，先加进本规范，再在代码里用。宁可多一个 token，也不要在组件里写一个孤立的色值。
